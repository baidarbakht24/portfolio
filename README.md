# Baidar Bakht - Personal Portfolio Website

A modern, responsive, high-performance portfolio website built for **Baidar Bakht** (Penn State Information Technology & Cybersecurity).

---

## 🌟 Features Included

1. **Clean Single-Page Experience:**
   - Dedicated hero section highlighting your name, status, Penn State education, GPA (3.7 / Dean's List), and IT & Cybersecurity ambitions.
   - Professional summary tailored to database hygiene, AMS migration, and foundational security.
   - Comprehensive **interactive resume section** formatted to match your official resume layout.
   - Detailed **internship & professional experience** timeline (Mon Yough Area Chamber of Commerce & Children's Place).
   - Featured **Python-Based ATM Simulator** project breakdown with code snippet and defensive architecture overview.
   - Categorized **Skills & Competencies** matrix (Programming, Security, IT Operations, Professional Strengths).
   - Fast **Contact & Connect** section with mailto generation and quick-copy clipboard support.
   - Print-friendly CSS (`Ctrl + P` / Save as PDF).

2. **Tech Stack:**
   - HTML5 & Modern Vanilla JavaScript
   - Tailwind CSS (via CDN)
   - Lucide Icons
   - Inter / Plus Jakarta Sans & JetBrains Mono typography

## 🚀 How to Run Locally

### Option 1: Quick Launch
Double-click `start_server.bat` in this folder. It will start Python's built-in web server and immediately open your browser to:
[http://localhost:8000](http://localhost:8000)

### Option 2: Terminal / PowerShell
Open PowerShell or Command Prompt in this folder and run:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your web browser.
